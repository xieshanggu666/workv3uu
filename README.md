# 📡 舆舟 · 全网舆情监测与危机管理平台

基于 **Vue 3 + Vite + Pinia（前端）+ Express + SQLite（后端）** 的舆情监测与危机处置演示平台。所有数据为 mock，模拟舆情采集与处置闭环。

## 技术栈

- 前端：Vue 3 + Vite + Pinia
- 后端：Node 内置 `node:sqlite` + Express，REST API
- 数据库：`server/pubmon.db`（SQLite，首次启动自动建表 + 预置示例舆情）

## 运行

```bash
npm install
npm run dev
```

前端 http://localhost:5200（Vite 已代理 `/api` 到 http://localhost:4130）。需 Node ≥ 22.13。

## 功能

- **舆情总览**：总量/正面/中性/负面/热点/负面占比统计、情感分布环形图、7 时段热度趋势、渠道来源分布、高频热词云、生效预警规则、危机速览
- **舆情列表**：按情感/渠道/关键词筛选，录入新舆情自动进行情感分析，负面舆情触发预警提示；支持批量导入（每行一条），整批事务处理、任一失败整体回滚，导入后统一刷新统计
- **预警中心**：预警规则配置（级别/关键词/情感/热度下限），规则启停、触发记录与关联舆情、单条/批量解除预警
- **危机处置**：事件建档（方案+研判+邮箱）、状态流转（监测→处置→结案）、处置时间线、动作记录、事件回溯与结案总结

## 预警 → 危机闭环

- **自动建档**：红/橙级预警触发时自动创建危机事件（记录来源规则与首条关联舆情）
- **去重并入**：同一规则存在未结案事件时，新触发不重复建档，自动并入其时间线（「预警再次触发」）
- **状态同步**：预警解除 → 危机时间线同步记录；危机结案 → 级联解除关联的未解除预警
- **回溯结案**：危机事件支持回溯（触发统计、关联舆情、完整时间线），结案时写入回溯总结完成闭环

## 批量导入

- `POST /api/posts/batch`：`{ items: [{ title, content, source_id, topic, media }] }`，单次最多 200 条
- 与单条录入共用同一管线：逐条情感分析 → 落库 → 预警触发 → 红/橙级危机自动建档或去重并入
- 整批预校验 + 事务执行，任一条失败整体回滚；成功后返回逐条结果、触发汇总与最新统计
- `POST /api/posts` 单条录入保持兼容，内部走同一管线，响应结构不变
